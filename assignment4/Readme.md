## Task 2: Deep's style (Fashion UI)

### Features
- Full layout built with CSS Grid (11 columns, named grid areas)
- Navbar with search, currency and cart icons
- Hero heading with a collage of 7 images
- Rotating "Explore More" circular text (SVG `textPath`)
- Handwritten signature using a Google Font
- Quote, scroll down button and article section

### Technologies Used
- HTML5
- CSS3 (Grid, Flexbox, Animations)
- Google Fonts
